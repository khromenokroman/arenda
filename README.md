# arenda

Составление договоров аренды нежилого помещения. Веб-сервер на C++ с интерфейсом в браузере:
пользователь ведёт справочники арендодателей и арендаторов, заполняет условия договора и получает
готовый к печати договор.

Состояние: справочники, заполнение по ИНН, создание договоров с делением срока, печать (версия 0.9.0.0).

## Арендодатели

Раздел «Арендодатели» (арендодатель всегда организация, ООО): организация (наименования, ОГРН, ИНН, КПП, адрес, телефон), подписант (должность и ФИО
в именительном и родительном падеже, основание полномочий), банк (р/с, банк, БИК) и сдаваемый объект
(название и регион в родительном падеже, адрес, место заключения договора). Родительный падеж вводится
вручную: в договор2026-10-19-500100732259е стоит «в лице директора Иванова Ивана Ивановича», автоматическое склонение фамилий ошибается.

Раздел «Объект аренды» хранит также режим работы (п. 2.2.1 договора). Раздел «Условия договоров»: штраф
за нарушение пожарной безопасности (п. 5.1.7, по умолчанию 5 000 руб.), наибольшая сумма одного договора
(100 000 руб.) и общий срок аренды (11 месяцев, не больше 11: договор меньше года не регистрируется).
По сумме и сроку срок аренды делится на несколько договоров.

Обязательны полное и краткое наименования и условия договоров, остальное можно заполнить позже: пустое поле в договоре
печатается прочерком. Заполненные реквизиты проверяются: контрольные цифры ИНН и ОГРН, формат КПП и БИК,
контрольный ключ расчётного счёта вместе с БИК.

## Договоры

Раздел «Договоры» → «Создать договоры»: выбирается арендодатель и строки «арендатор, дата начала, плата
в месяц». «Рассчитать» показывает договоры, которые будут созданы, «Создать договоры» записывает их.

Срок аренды из карточки арендодателя (по умолчанию 11 месяцев) делится на несколько договоров подряд так,
чтобы плата за срок каждого не превышала наибольшую сумму договора (по умолчанию 100 000 руб.).
В договор помещается `сумма / плата` месяцев (не больше срока), число договоров берётся наименьшее,
месяцы распределяются поровну:

| Плата в месяц, руб. | Договоры, мес. |
|---|---|
| до 9 090 | 11 |
| 9 091 – 16 666 | 6 + 5 |
| 16 667 – 25 000 | 4 + 4 + 3 |
| 25 001 – 33 333 | 3 + 3 + 3 + 2 |
| 33 334 – 50 000 | 2 + 2 + 2 + 2 + 2 + 1 |
| больше 50 000 | 11 договоров по месяцу |

Границы считаются от даты начала: аренда с 31 января даёт части с 31.01, 31.03, 31.05, а не съезжает
на 28-е после февраля. Номер договора: дата начала части и ИНН арендатора, `2026-10-19-500100732259`;
второй договор с той же датой у арендатора не создастся.

В договор копируются карточки арендодателя и арендатора (с арендуемым местом) и оборудование на момент
создания: правка карточек не меняет созданные договоры. Кнопка «Обновить из карточек» в договоре
забирает текущие данные. Арендодателя или арендатора с договорами удалить нельзя.

## Печать

«Печать» в договоре открывает печатную форму в новой вкладке; в списке договоров флажками выбирается пачка
(«Печать выбранных»), после создания договоров есть «Напечатать созданные». Печать из браузера (Ctrl+P),
в том числе в PDF; в настройках печати лучше выключить «Колонтитулы».

Текст договора из образца, шаблон `templates/contract.html` вшивается в программу при сборке. Подставляются
реквизиты сторон, вступление по виду арендатора (ИП, организация, физлицо с паспортом), «именуемый/именуемая/
именуемое» и «действующего/действующей» по полу, плата прописью («20 000 (Двадцать тысяч) рублей 00 копеек»),
даты («19» октября 2026 г.), этаж, назначение, режим работы, штраф, регион для суда, перечень оборудования.
Незаполненное поле печатается прочерком для заполнения от руки. Приложения: № 1 перечень электрооборудования,
№ 2 лист ознакомления с инструкцией о пожарной безопасности (схема расположения из образца убрана).

Договор всегда занимает ровно 4 страницы A4, то есть 2 листа при двусторонней печати: шрифт 8,5 pt Times
New Roman (или совпадающий с ним Liberation Serif), поля 8-13 мм. В пачке каждый договор начинается с нового
листа. `tests/print_pages.sh` печатает в PDF договор с минимальными данными и с длинными реквизитами
и 10 строками оборудования и проверяет число страниц; при другом шрифте число страниц может отличаться.

## Заполнение по ИНН и БИК

Кнопка «Заполнить по ИНН» в карточке арендодателя и арендатора (организация, ИП) берёт данные из ЕГРЮЛ
и ЕГРИП через [DaData](https://dadata.ru/api/find-party/): наименования, ОГРН или ОГРНИП, КПП, адрес,
должность и ФИО руководителя; у ИП ФИО и пол по отчеству. «Заполнить по БИК» подставляет название банка.
Данные попадают в форму с подсветкой и сохраняются только кнопкой «Сохранить».

Должность и ФИО руководителя в родительном падеже («генерального директора Петрова Петра Павловича»)
составляются по правилам склонения: на распространённых фамилиях они верны, на редких возможна ошибка,
поэтому их нужно проверить. Физлицо по ИНН не заполняется: паспорт и адрес в открытых реестрах не публикуются.

Нужен API-ключ из личного кабинета dadata.ru (бесплатно до 10 000 запросов в день), секретный ключ
не нужен. Ключ передаётся серверу переменной окружения:

```sh
ARENDA_DADATA_KEY=ваш_ключ ./build/arenda --db arenda.db --web web
```

Без ключа или без интернета кнопки показывают причину, ручной ввод работает как обычно. В DaData уходит
только ИНН или БИК.

## Арендаторы

Раздел «Арендаторы», три вида:

| Вид | Поля |
|---|---|
| Индивидуальный предприниматель | ФИО, пол, ОГРНИП, ИНН (12 цифр), адрес, телефон, банк |
| Организация | наименования, ОГРН, ИНН (10 цифр), КПП, адрес, телефон, подписант как у арендодателя, банк |
| Физическое лицо | ФИО, пол, дата рождения, ИНН (необязателен), адрес регистрации, телефон, паспорт (серия и номер, кем и когда выдан, код подразделения), банк |

ИНН обязателен у всех видов и не повторяется: из него и даты начала строится номер договора.

Раздел «Арендуемое место» у всех видов: площадь по напольной плитке и площадь для торговли (кв. м), этаж,
назначение помещения для п. 1.3 («для оказания услуг по металлоремонту (...)»), вид деятельности коротко
для п. 2.1.2 («необходимые для металлоремонта»), состояние помещения при передаче. Ниже таблица оборудования
для приложения 2: наименование, марка, мощность в кВт, количество; суммарная мощность считается сама.

Пол нужен для «именуемый» или «именуемая» в договоре. При смене вида общие поля (ФИО, ИНН, адрес, банк)
переходят в новую форму, поля прежнего вида при сохранении очищаются.

Паспортные данные физлиц хранятся в файле базы без шифрования, а входа по паролю нет. Защищайте файл
базы и не открывайте сервер в сеть (`--host 0.0.0.0`) без необходимости.

## Сборка

Debian 12 или 13:

```sh
sudo apt install build-essential cmake libsqlite3-dev libssl-dev nlohmann-json3-dev libgtest-dev libgmock-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
ctest --test-dir build --output-on-failure
```

cpp-httplib лежит в `third_party/httplib.h` (header-only, v0.18.7, лицензия MIT в `third_party/httplib-LICENSE`).

## Запуск

```sh
./build/arenda --db arenda.db --web web
```

Интерфейс открывается по адресу http://127.0.0.1:8080/. Ключи:

| Ключ | По умолчанию | Назначение |
|---|---|---|
| `--db ФАЙЛ` | `arenda.db` | файл базы SQLite, создаётся при первом запуске |
| `--host АДРЕС` | `127.0.0.1` | адрес для входящих соединений; `0.0.0.0` открывает доступ из сети |
| `--port ПОРТ` | `8080` | порт HTTP |
| `--web КАТАЛОГ` | `/usr/share/arenda/web` | каталог страниц интерфейса |
| `--dadata-url АДРЕС` | `https://suggestions.dadata.ru/suggestions/api/4_1/rs` | API подсказок DaData (для тестов) |

Входа по паролю нет: при `--host 0.0.0.0` справочники и договоры видны всем в сети.

## API

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/api/version` | `{"version": "0.9.0.0", "schema": 6}` |
| GET | `/api/landlords/fields` | описание полей карточки: `[{"key", "label", "group", "hint", "required", "input", "choices"}]` |
| GET | `/api/landlords` | список `[{"id", поля...}]` по краткому наименованию |
| POST | `/api/landlords` | создать из `{"поле": "значение"}`, ответ 201 с карточкой |
| GET | `/api/landlords/{id}` | карточка |
| PUT | `/api/landlords/{id}` | изменить переданные поля, остальные не трогаются |
| DELETE | `/api/landlords/{id}` | удалить, ответ 204 |
| GET | `/api/tenants/kinds` | виды арендаторов с полями: `[{"code", "label", "fields"}]` |
| GET | `/api/tenants` | список с `title` (название) и `kind_label` (вид) |
| POST | `/api/tenants` | создать из `{"kind": "ip", "поле": "значение"}`, ответ 201 |
| GET | `/api/tenants/{id}` | карточка |
| PUT | `/api/tenants/{id}` | изменить переданные поля; `kind` меняет вид |
| DELETE | `/api/tenants/{id}` | удалить, ответ 204 |
| GET | `/api/tenants/{id}/equipment` | оборудование `[{"name", "model", "power": "0,55", "qty"}]` |
| PUT | `/api/tenants/{id}/equipment` | заменить перечень оборудования целиком |
| POST | `/api/contracts/plan` | расчёт без записи: `{"landlord_id", "rows": [{"tenant_id", "start", "rent": "20 000"}]}` → договоры |
| POST | `/api/contracts` | создать договоры по тому же телу, ответ 201 со списком |
| GET | `/api/contracts` | все договоры: номер, сроки, `rent`, `total`, стороны, копии карточек |
| GET | `/api/contracts/{id}` | договор |
| POST | `/api/contracts/{id}/refresh` | обновить копии карточек сторон и оборудования |
| DELETE | `/api/contracts/{id}` | удалить, ответ 204 |
| GET | `/print/contracts/{id}` | печатная форма договора (HTML) |
| GET | `/print/contracts?ids=1,2,3` | пачка договоров в заданном порядке (HTML) |
| GET | `/api/lookup/party?for=landlord\|org\|ip&inn=ИНН` | `{"fields": {...}}` из DaData для карточки; 502 если DaData недоступен |
| GET | `/api/lookup/bank?bik=БИК` | `{"fields": {"bank": "..."}}` |

Ошибки приходят как `{"error": "текст"}` с кодом 400 (неверные данные), 404 (нет объекта или метода),
502 (DaData недоступен или отклонил ключ), 500.

## Проверки

CI (`.github/workflows/ci.yml`) на Debian 12 и 13 собирает проект, гоняет тесты и запускает сервер.
Веб-интерфейс проверяется в headless Chrome (нужны chromium или google-chrome и node):

```sh
tests/web_smoke.sh build/arenda web   # все страницы рисуются без ошибок, null и неэкранированного текста
tests/web_e2e.sh build/arenda web     # сценарии с кликами из tests/e2e/*.js
tests/print_pages.sh build/arenda web # договор ровно 4 страницы A4 (нужен pdfinfo из poppler-utils)
```

Отдельно на Debian 12 проверяются clang-format-16 (`.clang-format`) и clang-tidy-16 (`.clang-tidy`,
любое предупреждение считается ошибкой).
